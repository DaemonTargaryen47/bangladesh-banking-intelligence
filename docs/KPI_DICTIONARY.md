# KPI Dictionary

| KPI | Formula / meaning | Management interpretation |
|---|---|---|
| Total Assets | Bank's asset base | Scale and balance-sheet growth |
| Deposits | Customer funding | Funding franchise strength |
| Loans | Credit portfolio | Core earning asset |
| Net Profit | Profit after tax | Bottom-line performance |
| NPL Ratio | Non-performing loans / loans | Asset-quality risk; lower is generally better |
| ROA | Net profit / assets | Profit generated from asset base |
| ROE | Net profit / equity | Shareholder return |
| Capital Adequacy | Regulatory capital / risk-weighted assets | Loss-absorption capacity |
| Cost-to-Income | Operating expense / operating income | Efficiency; lower is generally better |
| Loan-to-Deposit | Loans / deposits | Funding deployment / liquidity pressure |
| CASA Ratio | Current + savings deposits / total deposits | Low-cost funding strength |
| Profit per Employee | Net profit / employees | Workforce productivity |
| Performance Score | Synthetic composite of ROA, ROE, NPL, CAR and efficiency | Peer benchmarking only; not a regulatory metric |
